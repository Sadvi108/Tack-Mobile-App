# Tack 0.2.0 — document opening and career paths

This is a prerelease for testing, continuing the v0.1.0 testing release. Android
version name is `0.2.0`; Flutter build number is `4000`. Flutter's split APKs
add architecture offsets, so each asset's Android version code is recorded in
the release manifest. The base number exceeds all v0.1.0 APK version codes.

## What changed

- Tap an uploaded resume to open a private local copy using the phone's document
  options. Android offers installed readers; iOS uses its document menu. File
  options remain available through a separate button.
- Browse 139 career paths across 39 fields in Radar and Paths. Each new path
  includes starter skills and nine roadmap tasks. These are career directions,
  not a promise of 139 current vacancies.
- The production database now includes the atomic AI-job, quota, private error
  report and application-command migrations. Duplicate paid CV requests reuse
  their job and reserve one action.
- Privacy, terms and support links now resolve to public pages.
- Photos remain uploadable and openable. CV feedback asks for a text PDF or
  Word `.docx` file instead of starting photo OCR that exceeds server limits.

## Download and install

Use `Tack-0.2.0-arm64-v8a.apk` for a 64-bit Android phone,
`Tack-0.2.0-armeabi-v7a.apk` for a 32-bit phone, or
`Tack-0.2.0-universal.apk` if unsure. The universal APK contains all supported
Android CPU architectures and has a larger download.

Open the APK on the phone and allow installation from the browser or Files app
if Android asks. This build uses the same release signing key as v0.1.0 and a
higher version code. Android can therefore install it as an update without
requiring an uninstall. Physical-device upgrade testing remains pending.

## Validation and limits

- Flutter analysis and formatting pass; 366 Flutter tests and 99 backend tests
  pass. Backend formatting, lint and all ten endpoint type checks pass.
- The 8 September live run passed 29 checks, including private downloads,
  text-PDF scoring, free CV checks, duplicate recovery and quota charging.
- Android release APKs are signed and their certificate, package and version
  are checked before publication. SHA-256 checksums and a release manifest are
  attached with the APKs.
- Opening in installed readers, camera permissions, OAuth and account recovery
  still need physical-device testing. Push device registration is incomplete.
- Photo/scanned CV feedback remains deferred. Use a text PDF or `.docx`.
